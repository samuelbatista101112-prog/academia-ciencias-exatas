# 🎓 Academia de Ciências Exatas

> Do fundamento à fronteira da ciência.

Plataforma de formação científica progressiva criada para Samuel Batista: diagnóstico adaptativo, mapa de conhecimento com nível de domínio 0–6, trilha com árvore de pré-requisitos até os temas de fronteira (matéria escura, energia escura, cosmologia, relatividade geral, mecânica quântica) e revisão espaçada.

## Método

*Camadas de ensino:* intuição → formalização → derivação → demonstração → aplicação → problema novo.

*Método socrático embutido:* nas questões do diagnóstico, a resposta não é entregue de imediato — são duas pistas graduais antes da solução, e acertar sozinho vale mais do que acertar com pista.

## O que tem

1. **Diagnóstico progressivo** — 30 questões em escada (Matemática → Física → Química → Computação → Pensamento científico), do nível fundamental ao de graduação. O ponto onde você para é dado de diagnóstico.
2. **Mapa de conhecimento** — nível de domínio 0–6 por assunto (0 desconhecido · 1 reconhecimento · 2 compreensão · 3 aplicação · 4 domínio · 5 capaz de ensinar · 6 pesquisa).
3. **Trilha até a fronteira** — 20 etapas com árvore de pré-requisitos: cálculo → álgebra linear → EDO → mecânica → eletromagnetismo → termodinâmica → estatística → relatividade → quântica → RG → QFT → partículas → astrofísica → cosmologia → ΛCDM → matéria escura. Cada etapa só abre com nível ≥ 3 em todos os pré-requisitos.
4. **Aulas completas** — cada aula segue as camadas do método, com derivações de verdade (a derivada nasce da definição do limite; a regra dos produtos notáveis nasce do desenho).
5. **Revisão espaçada** — intervalos 1→3→7→14→30→60 dias por assunto.
6. Progresso salvo localmente, funciona offline depois de aberto.

## Honestidade científica

Nada aqui marca um problema em aberto como resolvido. Teoria não vira lei, hipótese não vira descoberta. O app diagnostica e treina; o orientador principal continua sendo o assistente no chat.

## Stack

HTML + CSS + JavaScript puros, armazenamento local. Sem dependências, sem build, sem servidor.
